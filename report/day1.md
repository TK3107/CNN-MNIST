# Day 01 - CNN-MNIST

## 1. Mục tiêu
Tìm hiểu tổng quan project nhận dạng chữ số viết tay bằng Deep Learning
và chuẩn bị môi trường để thực hiện project.

## 2. Kiến thức đã tìm hiểu
- MNIST là bộ dữ liệu dùng cho bài toán nhận dạng chữ số viết tay.
- Ảnh MNIST có kích thước 28 × 28 pixel.
- CNN (Convolutional Neural Network) phù hợp với bài toán xử lý hình ảnh.
- Tìm hiểu sơ bộ về Conv2D, ReLU, MaxPooling, Flatten, Dense và Softmax.
- Tìm hiểu các khái niệm training, loss, optimizer, epoch, batch và accuracy.
- Tìm hiểu sơ bộ pipeline của project theo video hướng dẫn.

## 3. Công việc đã thực hiện
- Tạo project CNN-MNIST.
- Tạo virtual environment `.venv`.
- Cài đặt TensorFlow.
- Kiểm tra TensorFlow hoạt động thành công, phiên bản 2.21.0.
- Khởi tạo Git repository.
- Tạo `.gitignore` để bỏ qua `.venv`.
- Tạo repository trên GitHub và push commit đầu tiên.

## 4. Vấn đề gặp phải
Ban đầu chưa hiểu rõ Git, commit và cách kết nối repository
local với GitHub. Sau khi tìm hiểu và thực hiện từng bước,
đã có thể tạo commit và push project lên GitHub.

## 5. Kế hoạch tiếp theo
- Tìm hiểu bộ dữ liệu MNIST.
- Tải và kiểm tra dữ liệu.
- Tìm hiểu tiền xử lý dữ liệu.
- Bắt đầu xây dựng mô hình CNN.
- Chạy thử quá trình huấn luyện.
